# Bawkward — 방법론에서 구현으로

> 형님 노트(“핵심아이디어를 탐구질문으로 돌리고, 학생이 먼저 써 본 뒤, 원문은 볼트에 남는다”)를
> 반박가능성(falsifiability) 기준으로 **사실 / 설계 판단 / 미검증**을 갈라 정리한다.
> 이 문서는 외부 사이트를 크롤링·복제한 결과가 아니라, 공개된 교육과정·보안 상식과 방법론에서 **귀추**한 설계다.

## 0. 이름의 논리 — 왜 Bawkward인가

- **Backward Design (이해중심 교육과정)**: 진도(총론→각론)가 아니라 **도달점(GOAL)에서 거꾸로** 설계한다.
  Wiggins & McTighe의 UbD이자, 2022 개정 교육과정이 채택한 설계 원리. → ①도달점 → ②평가(인출·전이) → ③활동(일견쓰).
- **(a)wkward**: 학생이 배우기 **전에 먼저 어색하게 써 본다**. 사전 인출·생성이 이해를 만든다(테스트 효과·생성 효과).
- 합쳐서 **Bawkward** = 거꾸로 설계 + 먼저 어색하게 쓰기. 로고 `B`가 좌우로 뒤집힌 것도 같은 뜻이다.

## 1. 루트 객체 — 핵심아이디어

형님 노트의 확정: 루트는 학급도, 앱도 아니라 **핵심아이디어(CoreIdea)**다.

```
Unit(핵심아이디어)
  ├─ 내용 체계 (지식·이해 / 과정·기능 / 가치·태도)   ← 2022 개정 세 범주
  ├─ 성취기준 + 해설
  ├─ 도달점(GOAL)
  └─ Inquiry(탐구질문, 연역)
        └─ 차시질문
Work(일견쓰: 관찰→질문→탐구→사유)   ← 학생 원본, 볼트에만
Retrieval(인출: 키워드=배점) → Gap(안 떠오른 것)
Transfer(전이: 내용교과→도구교과→실생활, 체크 3칸)
Run(AI 호출: masked_input · question_draft · accepted_by, 원문 없음)
Signal(주간 비식별 신호) → STATEtistics
AccessLog(누가·언제·무엇을)
```

## 2. 학습 루프 (구현된 화면)

| 단계 | 방법론 | Bawkward 화면 | 누가 |
|---|---|---|---|
| ① 도달점 | 핵심아이디어·성취기준에서 GOAL 확정 | `#/unit/:id` 단원 헤더(도달점 강조) | 교사 |
| ② 탐구질문 | GOAL에 닿기 위해 **연역** | `#/unit/:id` 탐구질문 + 차시질문 | 교사 |
| ③ 일견쓰 | 관찰→질문→탐구→사유를 **먼저** 쓴다 | `#/write/:unitId` 4단 폼 | 학생 |
| ④ 인출·갭 | 키워드로 도달 점검, 안 떠오른 것=보충 | `#/retrieve/:unitId` | 교사(설계)/학생(인출) |
| ⑤ 전이 | 내용교과→도구교과→실생활 | `#/transfer/:workId` 3칸 체크 | 학생 |
| — | 학급 문집(내부만) | `#/board/:unitId` | 교사 |
| — | 학기 신호 추이 | `#/stats` STATEtistics | 모두 |

**AI의 자리(불변식):** 일견쓰 4단을 **모두 쓴 뒤에만** “다음 질문 받기”가 열린다. AI는 답·완성글을
주지 않고 **다음 탐구질문 초안**만 낸다. 학생이 수용/거절한다. (코드: `viewWrite`의 버튼 `disabled`,
`ai.js`의 `draftInquiries`, 시스템 프롬프트 `SYS`.)

## 3. 데이터 주권 — 화면으로 강제한 원칙

| 원칙 | 구현 | 반증 조건(falsifier) |
|---|---|---|
| 원본은 로컬 볼트 | `data.js`가 localStorage에만 저장, `.md/.json` export | 원문이 네트워크로 나가면 위반 |
| 학생이 먼저, AI는 나중 | 4단 완성 전 AI 버튼 잠금 | 빈 글로 AI가 열리면 위반 |
| 외부엔 비식별 텍스트만 | `ai.maskPII` — 이름→[학생A], 학교→[학교], 번호→[N], 전화→[전화] | 원문 이름이 요청에 실리면 위반 |
| 호출은 원장에 기록 | `logRun`: masked_input·question_draft·accepted_by (원문 컬럼 없음) | 원장에 원문이 있으면 위반 |
| 학기말 파기 | `purgeTerm` — 원문·코드표·신호 동시 삭제 | 파기 후 원문이 남으면 위반 |
| 인가는 객체 단위 | `canAccessUnit` — 반·역할·배정 재검증, 학생은 문집 차단 | ID만 바꿔 남의 자료가 보이면 위반 |

`#/vault`에 실제 마스킹 예시와 Run 원장·접근 로그를 노출해, 주장이 아니라 **관찰 가능한 상태**로 만든다.

## 4. STATEtistics — 숫자만 남기는 학기 축

- 볼트가 매주 **비식별 신호**(주차·학급 내 가명 코드·인출 적중·갭·전이·리듬)만 append.
- 그래프는 학생 글을 담지 않는다. `semesterSeries()`가 주별 평균만 계산해 SVG 라인차트로 그린다.
- “가진 것/갖지 않은 것”을 화면에 명시 — 이름·원문·외부 전송은 **갖지 않는다**.

## 5. 사실 / 판단 / 미검증

- **사실(교육과정)**: 2022 개정은 내용 체계를 지식·이해 / 과정·기능 / 가치·태도 세 범주로, 성취기준과 함께 제시한다. 백워드 설계를 설계 원리로 삼는다.
- **설계 판단(우리 선택)**: 루트를 핵심아이디어로, 학급을 인가의 그릇으로, AI를 “질문 초안”으로 한정. 공개 링크·광고·외부 분석 SDK를 넣지 않음.
- **미검증(다음 단계)**: 실서버 프록시(브라우저 마스킹을 교내 서버로 이전), 교내 파일 동기화(NAS/Git), 진단 척도의 타당도, i18n.

## 6. 다음 단계

1. `data.js` 스토어 계층을 교내 REST로 치환(인증·권한·감사 로그를 서버에서 재검증).
2. `ai.js`의 마스킹·Run 로깅을 **서버 LLM 프록시**로 이전(브라우저는 원문도 키도 다루지 않게).
3. 볼트 동기화: 교내 NAS 또는 Git. 원문은 학교 밖으로 나가지 않게.
4. 접근성: 모달 포커스 트랩, 차트 대체 텍스트(현재 값은 텍스트로도 제공), 명도 대비 재점검.
