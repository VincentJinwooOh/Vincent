# 초등 3~4학년군 영어 — 2022 개정 교육과정 (초3 시작)

> 상태 표기: **[확인]** 확실 · **[검색확인]** 이번 검색에서 문장까지 확인 · **[대조필요]** 형님 원문 문서로 확정

## 1. 성격·적용

- **[확인]** 초등 영어는 **3학년부터** 시작한다. 3~4학년군은 **음성언어(듣기·말하기)** 중심이며 **문자언어(읽기·쓰기)**는 기초를 도입한다.
- **[확인]** 2022 개정 영어과 교육과정은 초등 3~4학년군에 **2025학년도부터 연차 적용**되었다(초3 → 2025, 초4 → 2026).
- **[확인]** 소리와 철자의 관계(파닉스), 일상적·친숙한 소재 중심의 쉽고 간단한 언어 사용이 원칙.

## 2. 영역 구조 — 4영역 → 2영역 재구조화

- **[확인]** 기존 4기능(듣기·말하기·읽기·쓰기)을 **이해(Reception)**와 **표현(Production)** 두 영역으로 재구조화했다.
  - **이해** = 듣기 + 읽기 → 성취기준 코드 **[4영01-□□]**
  - **표현** = 말하기 + 쓰기 → 성취기준 코드 **[4영02-□□]**
  - (코드의 `4`는 3~4학년군을, `영`은 영어과를, `01/02`는 이해/표현 영역을 뜻한다.)

## 3. 내용 체계 (세 범주)

- **[확인]** 모든 영역은 **지식·이해 / 과정·기능 / 가치·태도** 세 범주로 구성된다.

| 범주 | 3~4학년군 영어에서의 내용 요소(개요) | 상태 |
|---|---|---|
| 지식·이해 | 소리·철자·낱말·어구·문장, 기초 어휘, 기본 문장 구조, 친숙한 소재의 담화/글 | [확인] |
| 과정·기능 | 듣고/읽고 의미 파악, 세부정보 파악, 따라 말하기, 낱말·문장 쓰기, 전략 활용 | [확인] |
| 가치·태도 | 흥미·자신감, 참여·협력, 타 문화 존중, 의사소통 의지 | [확인] |

- **[대조필요]** 핵심 아이디어(영역별 1~2문장)의 **정확한 문장**은 고시 원문/형님 문서로 확정.
  - 이해(개요): *담화·글의 의미는 목적·맥락에 맞는 적절한 전략을 통해 효과적으로 이해된다.*
  - 표현(개요): *생각·느낌은 목적·상황에 맞게, 다양한 매체·전략을 활용해 표현·소통된다.*

## 4. 성취기준

### 4-1. 검색으로 확인된 문장 (원문 그대로)

- **[검색확인]** `[4영01-07]` 적절한 전략을 활용하여 담화나 문장을 듣거나 읽는다.
- **[검색확인]** `[4영01-08]` 다양한 매체로 표현된 담화나 문장을 흥미를 가지고 듣거나 읽는다.
- **[검색확인]** `[4영01-09]` 시, 노래, 이야기를 공감하며 듣는다.
- **[검색확인]** `[4영02-09]` 적절한 매체나 전략을 활용하여 창의적으로 의미를 표현한다.

## 6. Bawkward 단원 매핑 제안 (시드 후보)

핵심아이디어에서 도달점을 거꾸로 세우는 Bawkward 방식으로 옮기면:

- **핵심아이디어**: "쉽고 친숙한 영어는 소리로 먼저 만나고, 흥미를 가지고 듣고 따라 말하며 익힌다."
- **도달점(GOAL)**: 친숙한 소재의 쉬운 영어 노래·이야기를 흥미를 갖고 듣고, 인사·자기소개를 말과 글로 표현할 수 있다.
- **내용체계 매핑**:
  - 지식·이해: 알파벳·소리·기초 낱말·인사 표현
  - 과정·기능: 듣고 따라 말하기, 세부정보 파악, 낱말 쓰기
  - 가치·태도: 흥미·자신감, 공감하며 듣기
- **탐구질문(연역 예시)**: "같은 인사도 왜 상황마다 다르게 말할까?" / "노래로 배우면 왜 더 잘 외워질까?"
- 근거 성취기준: `[4영01-08]`, `[4영01-09]`, `[4영02-09]` (검색확인) + 표의 [대조필요] 항목.
