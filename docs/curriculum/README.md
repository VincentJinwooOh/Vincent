# 2022 개정 교육과정 정리 — 초3 영어 · 초6 과학

이 폴더는 Bawkward 단원(핵심아이디어→도달점→탐구질문)에 반영하기 위해,
**2022 개정 교육과정**의 초등 3~4학년군 영어 / 5~6학년군 과학을 정리한 자료다.

## 신뢰도 표기 규칙 (반박가능성)

각 항목 앞에 상태를 붙인다.

- **[확인]** — 공개 검색 결과 또는 교육과정 상식으로 확실한 사실(구조·범주·코드 체계 등)
- **[검색확인]** — 이번 웹 검색에서 문장/코드까지 확인된 성취기준
- **[대조필요]** — 구조는 맞으나 개별 문장·번호는 교육부 고시 원문(별책) 또는 **형님 문서로 최종 확정**해야 하는 부분

## 이번 조사의 한계 (정직하게)

- 이 작업 환경의 네트워크 프록시가 한국 교육 도메인(NCIC, 나무위키, 시도교육청,
  교과서사 등)의 원문 페이지 접근(egress)을 대부분 **차단**했다.
- 따라서 **개별 성취기준 전문(全文)을 고시 원문에서 그대로 복사하지는 못했다.**
- 대신 ①웹 검색으로 확인된 문장, ②교육과정의 확실한 구조를 싣고,
  나머지는 **형님이 건네주실 원문 문서로 채우고 대조**할 수 있게 표(체크란)로 비워 두었다.

## 원문 출처 (형님이 원문 확보 시 우선순위)

- **교육부 고시 제2022-33호** 별책 — 영어과(별책14), 과학과(별책9)
- 국가교육과정정보센터(NCIC) — 교육과정 원문·해설서
- 한국교육과정평가원(KICE) — 성취기준·성취수준 자료
- 시도교육청 성취수준 자료(예: 경남교육청 "성취기준별 성취수준(초등학교)")

## 파일

- `english_3-4_2022.md` — 초3 포함 3~4학년군 영어
- `science_5-6_2022.md` — 초6 포함 5~6학년군 과학
- 각 문서 끝에 **Bawkward 단원 매핑 제안**(시드로 넣을 후보)을 둔다.

## 앱과의 연결 (2차 세션)

- 각 문서 끝의 **단원 매핑 제안**은 `assets/js/data.js`의 `BW.TEMPLATES` 세 개(`tpl-eng3`, `tpl-sci6-energy`, `tpl-sci6-season`)로 옮겨져 있다.
- 단원 설계 모달 → “교육과정 템플릿” 선택 → 단원·탐구질문·인출 키워드가 한 번에 생성된다.
- 성취기준의 `note`가 `검색확인`/`대조필요`이면 단원 화면에 칩으로 표시된다. 원문 확정 시 템플릿의 `note`를 지우고 문장을 바꾸면 된다.

## 형님 문서 반영 절차

1. 형님이 원문 문서(hwp/pdf/한글 표)를 건네주신다.
2. 아래 각 문서의 **[대조필요]** 표에 성취기준 코드·문장을 채워 확정한다.
3. 확정본을 `assets/js/data.js`의 `BW.TEMPLATES`(및 필요 시 시드 `units`)로 옮겨 Bawkward에 반영한다.
