# 계절별 태양의 남중 고도와 낮의 길이 — 수업 웹앱

초등 과학 「계절의 변화」 단원용 인터랙티브 수업 자료입니다. 서버 없이 `index.html` 하나로 동작하며,
GitHub Pages(Jekyll)에서는 `/class/sun-altitude/` 경로로 서빙됩니다.

## 수업 흐름 (7단계, 화면 상단 탭 / 키보드 ← →)

| 단계 | 내용 | 교과서 대응 |
|---|---|---|
| 1 도입 | 여름·겨울 오후 6시 장면 좌우 비교 슬라이더, 시각 바꿔 보기, 답 쓰기(예시 버튼) | 파트 1 도입 |
| 2 배울 내용 | 학습 목표, 용어(남중·남중 고도·낮의 길이) | 파트 1 |
| 3 조사 방법 | 한국천문연구원 생활천문관 링크 3단계 + 오프라인 계산기 | 파트 1 |
| 4 가상 관측 | 남쪽 하늘 시뮬레이션(월 선택, 시각 슬라이더, 하루 재생, 남중 이동), 12달 관측 기록 | 파트 1 「어떻게 할까요?」 |
| 5 탐구 활동 | ① 모눈 위 꺾은선그래프 직접 찍기(1칸 = 1° / 6분) + 예시 보기 ② 비교 표 정답 확인 ③ 추론 빈칸 + 반례 탐색(적도·남반구·북극권) | 파트 2 탐구 활동 1·2·3 |
| 6 남중 고도 변화 | 계절 버튼(여름/겨울/봄·가을)별 태양 경로 그림, 세 계절 겹쳐 보기, 태양 움직이기 | 파트 2 「계절에 따른 태양의 남중 고도 변화」 |
| 7 정리 | 계절별 요약 카드 + 5문항 퀴즈 | 정리 |

## 계산 근거

`solar.js` 는 NOAA Solar Calculator(Meeus 근사식)를 구현한 것으로, 외부 API 없이 브라우저에서 계산합니다.
기본 관측 위치는 **인천(북위 37.456°, 동경 126.705°)** 이며, 상단에서 서울·강릉·대전·대구·광주·부산·제주로 바꿀 수 있습니다.

검증(인천, 2026년, `astral` 라이브러리와 비교): 남중 고도 오차 0.03° 이내, 일출·일몰·남중 시각 오차 1분 이내.
